# Docker Starter

โปรเจคตัวอย่างที่มี Dockerfile ของตัวเอง — สำหรับคนที่อยากคุม build/run เองทั้งหมด
ใช้ได้กับทุกภาษา ทุกเฟรมเวิร์ก ตราบใดที่เขียน Dockerfile ได้

## วิธี deploy

1. แก้ `Dockerfile` และโค้ดตามต้องการ (หรือ deploy ตามนี้เลยเพื่อทดสอบ)
2. ไปที่หน้า **Deploy** ในแดชบอร์ด
3. ลากทั้งโฟลเดอร์นี้มาวาง (หรือ zip โฟลเดอร์แล้วลากไฟล์ .zip มาวาง)
4. เลือก runtime **Docker** แล้วกด Deploy

## เงื่อนไขที่ต้องรักษาไว้

- ต้องมีไฟล์ชื่อ `Dockerfile` อยู่ที่ root ของโฟลเดอร์ที่อัปโหลด
- ใส่ `EXPOSE <port>` ใน Dockerfile เพื่อให้ระบบรู้ port อัตโนมัติ
  (ถ้าไม่ใส่ ต้องกรอก port เองในหน้า deploy)
- แอปข้างใน container ต้อง bind ที่ `0.0.0.0` ไม่ใช่ `localhost`
- ควรมี route ที่ตอบ HTTP 200 เร็วๆ (เช่น `/health`) เพื่อให้ healthcheck ผ่านไว
