# Static Site Starter

เว็บไซต์ HTML/CSS ธรรมดา deploy บนระบบนี้ได้ทันที — เหมาะกับหน้าเว็บทั่วไป landing page หรือเอกสาร

## วิธี deploy

1. แก้ `index.html` และ `styles.css` ตามต้องการ
2. ไปที่หน้า **Deploy** ในแดชบอร์ด
3. ลากทั้งโฟลเดอร์นี้มาวาง (หรือ zip โฟลเดอร์แล้วลากไฟล์ .zip มาวาง)
4. เลือก runtime **Static** แล้วกด Deploy

## สิ่งที่ควรรู้

- ต้องมี `index.html` อยู่ที่ root ของโฟลเดอร์
- ใส่ไฟล์ JS/รูป/ฟอนต์เพิ่มได้ตามปกติ — ทุกไฟล์ในโฟลเดอร์จะถูกเสิร์ฟ
- ถ้าเป็นแอป SPA (React/Vue ที่ build แล้ว มี client-side routing) ให้เปิดตัวเลือก **SPA**
  ตอน deploy เพื่อให้ route ที่ไม่ตรงไฟล์จริงตกไปที่ `index.html` แทนที่จะขึ้น 404
