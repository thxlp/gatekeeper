## A. ของใหม่รอบ 2026-08-08 (เสี่ยงสุด เทสก่อน)

- [ ] **login กด Enter ส่งฟอร์มได้** — เพิ่งเปลี่ยนจาก `<div>` เป็น `<form>` ทั้งหน้า
      พิมพ์อีเมล+รหัสผ่านแล้วกด Enter ในช่องรหัสผ่าน ต้องเข้าสู่ระบบเลย
      และปุ่ม "เข้าสู่ระบบ" ต้องยังทำงานเหมือนเดิม
      *ถ้าเบราว์เซอร์เด้งถามว่าจะบันทึกรหัสผ่านไหม = ดี แปลว่าฟอร์มถูกต้อง*
- [ ] **register / ลืมรหัสผ่าน** — กด Enter ได้เหมือนกัน ปุ่มยังทำงาน
- [ ] **2FA** (บัญชีที่เปิดไว้) — หน้ากรอกรหัส 6 หลักกด Enter ส่งได้
- [ ] **มือถือ: ออกจากระบบได้** — ย่อหน้าต่างให้แคบกว่า 640px
      ต้องเห็นปุ่มวงกลมรูปคนบนแถบบน → กดเข้า /account → ปุ่มออกจากระบบใช้ได้
      *เดิมมือถือเข้าหน้านี้ไม่ได้เลย นี่คือบั๊กที่หนักสุดที่แก้ไป*
- [ ] **มือถือ: ปุ่มไฟล์เริ่มงาน** — ไอคอนดาวน์โหลดข้างปุ่มบัญชี กดแล้วกล่องเปิด โหลด zip ได้
- [ ] **แดชบอร์ด → แก้ไขแอป** — dropdown runtime ต้องมีครบ 4 ตัว (node/static/python/docker)
      ถ้ามีแอป python อยู่ ให้เปิดแก้ไขแล้วเช็คว่าค่าที่แสดงตรงกับของจริง
- [ ] **อัปโหลด zip เกิน 50MB** — ต้องเด้งเตือนทันทีตั้งแต่เลือกไฟล์ ไม่ใช่รออัปโหลดจนจบ
- [ ] **กล่อง modal ด้วยคีย์บอร์ด** — เปิดกล่องไฟล์เริ่มงาน กด Tab วนต้องอยู่ในกล่อง
      ไม่หลุดไปข้างหลัง กด Esc ปิดได้ ปิดแล้วโฟกัสกลับมาที่ปุ่มที่กดเปิด
- [ ] **Settings → บัญชีที่เชื่อมต่อ → GitLab / Bitbucket** (ของใหม่)
      - paste token มั่วๆ → ต้องขึ้นข้อความภาษาไทยอ่านรู้เรื่อง ไม่ใช่ code ดิบ
      - Bitbucket ไม่กรอก username → ปุ่มต้องกดไม่ได้
      - paste token จริง → ขึ้น "เชื่อมต่อในชื่อ <username>"
- [ ] **deploy private repo ของ GitLab/Bitbucket** — ปลายทางจริงของฟีเจอร์ข้างบน
      เชื่อมบัญชีแล้ววาง URL repo ส่วนตัว ต้อง clone + deploy ผ่าน
- [ ] **สลับภาษา TH/EN** — ยังปกติหลังแก้ไฟล์ locale เพิ่ม

## เช็คแล้วด้วย curl ไม่ต้องเทสซ้ำ

หลัง deploy `978bf1e` ยืนยันแล้วว่า: backend :8089/:8090 healthz 200 ·
frontend :3000 ตอบ 200 · `/git-credentials/status` ตอบ 403 (route มีจริง ไม่ใช่ 404) ·
